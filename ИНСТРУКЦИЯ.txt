G112 PROGRAMMER — PWA для GitHub Pages

СОДЕРЖИМОЕ
- index.html — приложение
- manifest.webmanifest — настройки установки на Android
- sw.js — кеширование для офлайн-работы
- icon-192.png и icon-512.png — иконки

ПУБЛИКАЦИЯ НА GITHUB PAGES
1. Войдите на https://github.com/ или создайте аккаунт.
2. Нажмите New repository.
3. Назовите репозиторий: g112-programmer
4. Для бесплатного GitHub Pages выберите Public.
5. Создайте репозиторий.
6. Нажмите Add file → Upload files.
7. Загрузите ВСЕ файлы из этой папки (не сам ZIP): index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png.
8. Нажмите Commit changes.
9. Откройте Settings → Pages.
10. В разделе Build and deployment выберите Deploy from a branch.
11. Branch: main; Folder: /(root), затем Save.
12. Подождите завершения публикации. GitHub покажет HTTPS-адрес сайта.

УСТАНОВКА НА ANDROID
1. Откройте опубликованный HTTPS-адрес в Chrome на Android.
2. Дождитесь первой полной загрузки приложения (нужен интернет).
3. Откройте меню Chrome (⋮) → Установить приложение или Добавить на главный экран.
4. Подтвердите установку.
5. После первого успешного кеширования приложение должно открываться офлайн.

ВАЖНО
- GitHub Pages размещает статические файлы по HTTPS; вычисления остаются на телефоне.
- После изменения файлов на GitHub откройте приложение онлайн, чтобы обновить кеш.
- Это упаковка текущего прототипа v2. Геометрия лысок и G41/G42 ещё требуют доработки и проверки.
- Не запускайте сгенерированный текст программы на реальном станке без отдельной проверки программы, подводов/отводов, коррекции и станочных M-кодов.
